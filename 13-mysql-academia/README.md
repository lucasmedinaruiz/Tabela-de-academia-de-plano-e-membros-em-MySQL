# Banco de Dados de uma Academia

Projeto introdutório de MySQL com tema fictício (planos e membros).

## Conceitos praticados
- `CREATE DATABASE` e `CREATE TABLE`
- `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL` e `FOREIGN KEY`
- `INSERT`, `SELECT`, `WHERE`, `JOIN` e `GROUP BY`
- `UPDATE` e `DELETE`

## Como executar
Abra o MySQL Workbench e rode o arquivo `academia.sql`, ou use o terminal:
```
mysql -u root -p < academia.sql
```
